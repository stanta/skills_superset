- OWASP Secure Coding with AI Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Secure_Coding_with_AI_Cheat_Sheet.html

- SLSA Provenance specification: https://slsa.dev/spec/v1.1/provenance
- OpenSSF Scorecard: https://www.scorecard.dev/

Recurring controls: least privilege, untrusted external/tool content, independent authorization of sensitive actions, sandboxing, adversarial regression tests, immutable/pinned dependencies, provenance, and auditable gates.
