# Lecture Pack Generator

Create a full teaching package for a single session from scratch.

## Use this skill when

Apply this skill when the user needs a complete lecture/class package rather than one isolated artifact.

Typical triggers:
- "Prepare a lecture"
- "Create a full class package"
- "Need slides, activities, and timing"
- "Build a ready-to-teach session"

## Do not use this skill when

Do not use this skill when the user only needs one artifact, such as only slides, only exercises, or only a multi-week curriculum.

## Core workflow

1. Identify topic, audience, duration, format, and constraints.
2. Infer reasonable defaults when inputs are missing.
3. Produce a full package that usually includes:
   - time-coded lecture blueprint
   - slide deck outline
   - in-class activities
   - formative quiz or checks
   - tools/preparation checklist
   - concise learner handout
4. Ensure pedagogical flow:
   - hook
   - objectives
   - simple-to-complex development
   - activity shifts every 10-20 minutes
   - recap and next-step bridge
5. Adapt task and example types to the domain while preserving the same teaching structure.
6. Keep the package realistic for live delivery.

## Output requirements

Make all parts consistent with each other. Slide outline, activities, and handout should reinforce the same learning goals.

## Quality bar

Optimize for clarity, pacing, engagement, and classroom usability rather than maximal theoretical coverage.
