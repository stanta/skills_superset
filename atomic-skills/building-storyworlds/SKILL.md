# Building Storyworlds

## Core principle

Build a **story-generating system**, not an encyclopedia. Define a small number of consequential rules, then extrapolate their effects through characters, institutions, daily life, conflict, and history.

## Use this structure

1. **Premise and promise** — what kind of stories this world is built to produce; what emotional or thematic experience must remain recognizable.
2. **Hard constraints** — physics, magic/technology, mortality, travel, information, scarcity, law, ecology. Mark each as invariant, conditional, unknown, or belief-only.
3. **Consequences** — for every major rule ask: what changes in economics, warfare, family, religion, crime, medicine, education, status, and ordinary routines?
4. **Interconnections** — prefer one rule with many consequences over many unrelated novelties.
5. **Conflict surfaces** — identify where constraints create incompatible goals, unequal access, taboo, externalities, or institutional pressure.
6. **Negative space** — reserve mysteries and unmapped areas intentionally. Unknown is not a contradiction.
7. **Entry points** — ensure a new reader can understand the current story without consuming the entire lore archive.

## World rule record

For every consequential rule keep:

- statement;
- scope;
- limitations / costs / failure modes;
- first canonical source;
- known exceptions;
- what characters believe versus what is author-level fact;
- narrative consequences;
- unresolved questions.

## Quality tests

A mature world should pass these checks:

- **Depth before breadth:** can existing rules generate new stories without inventing a new subsystem?
- **Constraint test:** do powers and institutions have meaningful limits and costs?
- **Consequence test:** do major rules visibly change society and behavior?
- **Conflict test:** does the world naturally create recurring dilemmas?
- **Mystery test:** is some space left unexplained without becoming arbitrary?
- **Accessibility test:** can a newcomer enter through the current story?

## Common failures

- **Worldbuilder's disease:** large lore volume with little effect on plot or character.
- **Novelty inflation:** adding powers, factions, species, dimensions, or technologies instead of deepening existing ones.
- **Exception creep:** every difficult scene introduces a special case.
- **Decorative systems:** politics/economics/religion exist as flavor but never constrain choices.
- **Exposition debt:** the audience must learn the manual before caring about the people.

When canon already exists, pair this skill with **governing-fiction-canon**. Before publication or a major handoff, use **auditing-lore-continuity**.
