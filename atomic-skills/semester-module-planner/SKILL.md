# Semester Module Planner

Design a multi-week learning arc for any discipline.

## Use this skill when

Apply this skill when the user needs a week-by-week module, syllabus, teaching sequence, or structured curriculum segment rather than a single lecture or a single worksheet.

Typical triggers:
- "Make a syllabus"
- "Plan a module for 8 weeks"
- "Sequence topics"
- "Create a weekly teaching plan"
- "Add homework and quizzes each week"

## Do not use this skill when

Do not use this skill when the user needs:
- a single-session lecture package
- only exercises or quizzes
- only slide text from an outline
- critique of existing lecture materials

## Core workflow

1. Identify the subject area, audience, duration, delivery format, and constraints.
2. Infer defaults when needed:
   - duration: 6-10 weeks
   - cadence: 1 session per week
   - session length: 80-90 minutes
   - audience: beginners unless stated otherwise
3. Organize content from foundational concepts to more complex application.
4. For each week, include:
   - 3 learning goals
   - 5-8 key concepts
   - time-coded session structure
   - one in-class activity
   - light homework
   - a short quiz with answers
   - a bridge to the next week
5. Add cross-module supports:
   - glossary of core terms
   - common misconceptions and correction strategies
   - recurrence/retrieval moments across weeks
6. Keep pacing realistic and cumulative.

## Output requirements

Produce a module plan that is teachable, progressive, and internally consistent. Make prerequisites visible and avoid overloading any single week.

## Quality bar

Prioritize coherence, repetition, and learner progression over maximal topic coverage. Make the plan reusable across institutions and delivery contexts unless the user specifies local constraints.
