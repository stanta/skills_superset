# Auditing Lore Continuity

## Core principle

Audit **claims against sourced canon**, not vibes against memory. Distinguish a contradiction from ambiguity, mystery, unreliable narration, and an intentional rule exception.

## Normalize facts first

Extract claims as structured records:

- entity;
- relation / property;
- value;
- branch;
- story time;
- source;
- source reliability;
- canon status.

Then compare new material against current canonical records.

## Contradiction classes

Check for:

- factual attribute conflict;
- temporal conflict;
- spatial / travel conflict;
- causal conflict;
- identity or lineage conflict;
- relationship-state conflict;
- knowledge-state conflict;
- capability / rule violation;
- possession / custody conflict;
- death / resurrection / availability conflict;
- branch contamination.

Also flag **soft drift**: characterization, tone, institutions or technology behaving differently without an in-world cause. Label soft drift separately from hard contradiction.

## Severity

- **Blocker:** impossible under current canon or breaks a major reader-visible promise.
- **Major:** repairable but affects multiple scenes or future plans.
- **Minor:** local inconsistency with low blast radius.
- **Intentional tension:** apparent contradiction that is a planned mystery, lie, misconception, or exception.

## Repair order

Prefer, in order:

1. verify source and scope;
2. reinterpret without changing facts;
3. add a bridge or missing event;
4. define a narrow exception with cost and provenance;
5. soft retcon;
6. branch / alternate continuity;
7. hard reboot.

Never silently overwrite the canon record.

## Continuity audit report

Return:

- finding ID;
- severity and class;
- conflicting claims with sources;
- affected entities/events;
- reader-visible impact;
- recommended repair;
- downstream updates required;
- whether canon approval is needed.

## Release gate

Before final publication, run checks across:

- chronology;
- character state;
- relationships;
- world rules;
- unresolved loops;
- cross-title / cross-media dependencies;
- canon change log.

Pair with **governing-fiction-canon** for rulings and **building-fiction-timelines** for time-related repairs.
