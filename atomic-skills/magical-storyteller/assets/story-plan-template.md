# План истории

## Контракт

Режим: create / analyze / repair / adapt.
Аудитория, язык, формат, объём, тон, канон, обязательное и исключённое.
Допущения: только действительно недостающие параметры.
Источник/редакция: обязательно при анализе чужого текста.

## Смысловое ядро

Логлайн: герой хочет ___, потому что ___; препятствие ___; цена неудачи ___.
Тема в форме вопроса: ___. Обещание аудитории: ___.

## Сцены

| Сцена | Хронология | Порядок показа | Ход | Функции или «нет метки» | Действие и причина | Изменение | Вопрос → ответ |

Для анализа добавь текстовое основание и уверенность: высокая / средняя / низкая.
Для неоднозначного эпизода дай альтернативу вместо ложной точности.

## Волшебное средство

Возможность, условие, ограничение, цена/компромисс, раннее введение, применение в финале.

## Психология и внимание

Попытка → последствие → следующий выбор. Выбранные приёмы внимания и места их работы.
Реестр открытых вопросов: введён → усилен → разрешён / сознательно открыт.

## Результат

Текст / сценарий / минимальная правка. Затем только заказанная аналитическая часть.
Проверка: причинность, исполнение обещания, канон, аудитория, источники и ограничения.
