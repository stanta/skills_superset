# GEO source notes

## Incorporated guidance

Included from [`/512-2/mcps/GEO-skillset.md`](/512-2/mcps/GEO-skillset.md:1) after validation and normalization:

- answer engines need crawl/index/snippet access
- pages should be built for citation extraction, not only ranking
- unique, evidence-backed, non-commodity content is preferred
- key answers should remain available in HTML text
- semantic HTML and accurate schema help machine understanding
- provenance and trust signals matter
- off-domain authority matters
- localization should go beyond translation
- GEO should be measured through prompts, citations, and referrals

## Constrained claims

- `llms.txt` is treated as optional/experimental rather than required
- exact uplift percentages and exact length thresholds were excluded
- strong causal claims about schema or Core Web Vitals were softened to best-practice guidance
