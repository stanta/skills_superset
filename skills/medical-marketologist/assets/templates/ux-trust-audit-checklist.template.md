# UX trust audit checklist (template)

## Clinician/expert presentation

- [ ] Clear clinician identity (name, photo)
- [ ] Credentials displayed (where legally appropriate)
- [ ] Scope of practice / specialization clear
- [ ] Video intro present (optional)

## Social proof

- [ ] Reviews/testimonials presented with context (no guaranteed outcomes)
- [ ] Proof is moderated and policy-safe
- [ ] No sensational before/after or implied diagnosis

## Trust signals

- [ ] Certifications/partnerships shown (if real)
- [ ] “Not for emergencies” guidance visible
- [ ] Clear escalation path (how to get urgent help)

## Privacy & security

- [ ] Privacy policy easy to find
- [ ] Data collection explained in plain language
- [ ] Consent language present where needed

## Red flags

- [ ] Outcome guarantees
- [ ] Fear-based claims
- [ ] Hidden disclaimers
