# Lecture Materials Improver

Review and improve existing teaching materials without discarding what already works.

## Use this skill when

Apply this skill when the user provides a draft lecture plan, slide deck, notes, script, or handout and wants critique plus a stronger revision.

Typical triggers:
- "Improve my lecture"
- "Review these slides"
- "Rewrite this draft"
- "Make it clearer and more structured"
- "Add activities and checks"

## Do not use this skill when

Do not use this skill when the user has no draft and needs a full package from scratch.

## Core workflow

1. Diagnose the draft before rewriting.
2. Check for:
   - hook, objectives, and agenda
   - simple-to-complex flow
   - logical transitions
   - manageable time blocks
   - readability and signal-to-noise ratio
   - activities, checks, recap, and closure
3. Preserve strong elements; replace only weak, redundant, or confusing parts.
4. Produce a structured improvement package that usually includes:
   - prioritized issues found
   - revised lecture/session plan
   - revised slide outline or rewritten sections
   - added activities and formative checks
   - prep checklist
5. Adapt examples, tasks, and vocabulary to the specific domain.
6. Optimize for teachability, not for maximum content density.

## Output requirements

Keep recommendations actionable. When rewriting, show a stronger version rather than vague advice alone.

## Quality bar

Reduce jargon, text walls, and abrupt transitions. Improve engagement without making the material gimmicky. Maintain the original intent unless the user asks for deeper redesign.
