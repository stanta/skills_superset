# Working Lecture Notes Generator

Create a teacher-facing session script that can be taught directly from notes.

## Use this skill when

Apply this skill when the user wants a working lecture script rather than a full slide deck, especially for live classroom delivery.

Typical triggers:
- "Create working lecture notes"
- "What should the teacher say?"
- "Make a board plan"
- "Give timing by blocks"
- "Prepare a lecturer script"

## Do not use this skill when

Do not use this skill when the user primarily needs slides, a full course plan, or only exercises.

## Core workflow

1. Identify topic, audience, duration, and assumed prior knowledge.
2. Infer reasonable defaults when missing.
3. Build a structured lecturer document containing:
   - session passport
   - goals and expected outcomes
   - plan of key questions or sections
   - detailed explanation notes for each section
   - examples or illustrations suited to the domain
   - likely misconceptions and corrective phrasing
   - attention-management cues
   - board plan
   - timing adjustments if ahead or behind schedule
   - recap, homework, and bridge to next topic
4. Write with delivery in mind: sayable phrasing, not textbook prose.
5. Mark where learners should write down definitions, models, formulas, arguments, or diagrams.

## Output requirements

Produce a single lecturer document that can be printed or used live with minimal extra preparation.

## Quality bar

Keep the narrative teachable, paced, and concrete. Balance formal definitions with simple explanations and examples.
