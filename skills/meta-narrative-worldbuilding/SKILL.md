# meta-narrative-worldbuilding

This is a first-level navigation skill. No CLI, scripts, MCP, or custom loader is required.

**Relative-path rule:** From the directory containing this `SKILL.md`, the atomic skill root is `../../atomic-skills/`. The catalog `references/members.md` is one directory deeper; its atomic paths therefore start with `../../../atomic-skills/`.

## Route by subtask

Open `references/members.md`, then read the full selected atomic `SKILL.md` files.

Typical decomposition:

- create or expand the fictional world → **building-storyworlds**;
- create a living universe/show/story bible → **maintaining-story-bibles**;
- define what is canonical or manage retcons/reboots → **governing-fiction-canon**;
- build or repair chronology → **building-fiction-timelines**;
- design a recurring cast and relationship system → **designing-character-systems**;
- plan dozens of installments and nested arcs → **planning-serialized-arcs**;
- check contradictions or the impact of a proposed change → **auditing-lore-continuity**.

For a new long-running universe, usually load 2–3 skills, not all seven. Start with the user's immediate deliverable; add canon/timeline/continuity support only where the scope requires it.

For visual character sheets, storyboards, video, illustration, layouts or other media execution, route that separate subtask to `meta-visual-design` or `meta-media-production`.

For research into historical, scientific or real-world grounding, route that separate subtask to `meta-research-knowledge`.

## Recommended quality gate

Before locking a major arc, publishing an installment, or approving a retcon, use **auditing-lore-continuity**.
